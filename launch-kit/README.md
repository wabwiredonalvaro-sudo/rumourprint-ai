# RUMOURPRINT AI — Launch playbook
**Prepared: 24 October 2026 | Fresh Exclusive Media**

## Positioning
RUMOURPRINT AI is a newsroom research assistant for connecting potentially related claims, comparing wording changes, and examining published evidence. It is not a definitive fact-checking or virality tracker.

## Public destinations
- Main FEM tools portal: https://tools.freshexclusivemedia.com/
- Web workspace: https://rumourprint-fem.streamlit.app/
- Android beta (testers only): https://github.com/wabwiredonalvaro-sudo/rumourprint-ai/releases/tag/android-v0.1.0-beta.1
- Privacy and responsible use: https://tools.freshexclusivemedia.com/privacy.html

## Launch gates
- [x] User confirmed FEM tools portal opens and links work on phone and computer.
- [x] User confirmed initial four app workflows tested.
- [x] Public Android beta release is available with clear debug-signing disclosure.
- [ ] Review privacy/limitations page with an FEM editor and publish it.
- [ ] Enable Cloudflare Web Analytics for the fem-tools Pages project if desired.
- [ ] Test the live app with 5-10 new non-sensitive examples; record failures and device/browser details.
- [ ] Choose an official feedback route (e.g., FEM website contact form); do not publish an invented email.
- [ ] Create stable release signing and release-policy documentation before promoting the APK beyond an invited test group.

## Rollout
**Day 1:** Publish FEM announcement on existing channels; point to the tools portal. Pin link where possible.

**Day 2:** Publish a 45-second screen-recorded walkthrough using fictional messages.

**Day 3:** Share a short explainer about why similarity is not proof that a claim is false.

**Day 4:** Invite 10-20 journalists, students and digital-literacy volunteers to test the web app with public examples. Share Android debug APK only with informed testers.

**Day 5:** Collect usability feedback and document broken links, ambiguous result labels and incorrect matches. Patch high-priority issues.

**Day 6:** Publish FAQ carousel/text. Make limitations and privacy notice easy to find.

**Day 7:** Review traffic, clicks and user feedback; choose the next development priorities and whether Android signing/release work can proceed.

## Measurements (first seven days)
- Landing page page views and visitors via Cloudflare Web Analytics (enable in Pages > fem-tools > Metrics > Web Analytics).
- GitHub beta asset download count (indicative; not unique users or installed devices).
- Number of volunteers who complete one investigation and one evidence search.
- Number of reports of wrong matches, broken links, unresponsive screens or download errors.
- Feedback from 5 journalists on clarity and ethical framing.

Avoid claiming factual accuracy, misinformation detection accuracy or public adoption metrics from these counters alone.

## Not ready to promise
- False-news verdicts or source attribution
- Private case storage / user accounts
- Offline Android intelligence
- Verified Luganda production reliability
- Play Store publication or signed stable Android release

## Responsible user reminder
No confidential source names, private conversations, health records or identifying details. Edited search queries may be sent to external news search services.
