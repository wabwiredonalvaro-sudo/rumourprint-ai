# RUMOURPRINT AI — Android Community Beta 2

**RUMOURPRINT AI — Built for everyone** · October 2026

## What it does

The native Android wrapper opens the RUMOURPRINT AI Streamlit investigation service. Live claim searches, X/social searches and internet picture matches require a network connection.

**The offline reading library works without internet.** The Android package includes 20 original RUMOURPRINT media-literacy explainers from the first installation, accessible from the **📚** book button in the app header. If the live service cannot load, the app opens its offline reading library as a fallback. On reopening the app online, it checks the published RUMOURPRINT library for newer guides and saves them for the next offline visit. These are original educational guides, not unlicensed copies of entire third-party news websites.

## Build from source

- Android Studio with SDK Platform 35 / Build Tools 35
- JDK 17
- Open the `android-app` folder
- Let Gradle sync
- Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**

The debug APK is normally created at:
`android-app/app/build/outputs/apk/debug/app-debug.apk`.

A newer APK can also be built via the **Build RUMOURPRINT Android APK** GitHub Actions workflow. Look for the `RUMOURPRINT-AI-Android-beta-build` artifact and the current beta 2 release tag.

## Limitations and next production steps

- Offline library articles are bundled and readable without connectivity; **offline AI investigation is not implemented**.
- Image upload and OCR depend on the hosted app for live search.
- The image investigation does not recognise real people from their faces, prove an image is fake, or estimate a percentage of pixels generated by AI.
- No public user accounts or persistent investigation history are currently offered.
- A shared community-note service requires a database configured by RUMOURPRINT; moderation is required before notes appear to other people.
- Before a Play Store launch, use stable private release signing, improve accessibility testing, implement abuse prevention and finalize the app privacy disclosures.
